模块由三个相互独立的子包组成，分别承担不同维度的可观测性职责：
- `metrics`：基于 `prometheus/client_golang` 暴露一组全局指标（Endpoint 请求/耗时、远程调用、Panic、业务错误、资源重试、WebSocket 连接数、LRU 缓存操作），通过 `sync.Once` 保证 `Init()` 幂等注册，所有指标名以 `carina_` 前缀统一命名。
- `tracing`：基于 OpenTelemetry SDK，通过 `Options`（Enabled/Endpoint/SampleRate）配置 OTLP HTTP exporter，启用时构建带采样率和服务名的 TracerProvider 并设置全局 TextMapPropagator；禁用时回退到无操作 tracer，`Tracer()`/`StartSpan()` 作为统一入口供上层埋点。
- `notify`：封装钉钉自定义机器人 Markdown 消息发送，通过 `DingBot` 结构体持有 `Options`（Token/BotName/Mode/PlatformName/APIURL/Timeout），在 develop 模式或无 Token 时降级为仅打印日志，避免误发生产告警。
三个子包之间无相互依赖，均被上层业务按需引入，属于横向横切的基础设施层。
