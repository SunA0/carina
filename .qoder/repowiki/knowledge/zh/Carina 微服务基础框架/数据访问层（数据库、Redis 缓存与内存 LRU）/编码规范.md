- 每个子包通过包级变量持有全局实例，并提供 Init 函数进行一次性初始化，未初始化时访问会 panic。
- 对外 API 普遍接受 context.Context 作为第一个参数，以便透传超时与事务信息。
- db 包通过 context key（TxKey）在请求链上传递事务句柄，业务代码统一通过 GetDBWithContext 获取当前 DB。
- lru 包采用函数式 Option 模式（WithTTL/WithEvictCallBack/WithNoReset）组合配置缓存行为。
- lru 包对读操作使用 RWMutex 读锁，写操作使用写锁，并在 metric 调用前检查指标是否已注册以保证 nil 安全。
