模块由三个并列子包组成，各自维护一个全局单例并通过 Init/Client 或 GetDB 暴露：
- db 包：基于 gorm.io/gorm，使用 sync.Once 初始化全局 *gorm.DB，通过 context key（TxKey）在请求链路中传递事务句柄；GetDBWithContext 优先返回上下文中的事务，否则回退到全局 DB；WithTransaction 封装 Begin/Commit/Rollback 并处理 panic 回滚。
- cache 包：基于 github.com/redis/go-redis/v9，Init 时 Ping 校验连通性，所有读写方法（Get/Set/HSet/MGet/ClearByPrefix 等）直接委托给全局 redis.Client。
- lru 包：自实现带 TTL 的内存 LRU，内部用 map + container/list 维护顺序，entry 上挂 time.Timer 做过期清理；通过 Option 函数式配置（WithTTL/WithEvictCallBack/WithNoReset），并发安全由 sync.RWMutex 保护，并通过 carina/metrics 上报 get/set/evict 指标。
依赖方向：lru 依赖 metrics，db 与 cache 相互独立，三者均被上层业务调用，不互相引用。
