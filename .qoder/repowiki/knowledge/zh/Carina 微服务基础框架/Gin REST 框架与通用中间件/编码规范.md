- REST 资源通过实现 `RestResourceInterface` 接口并以点分字符串返回资源名，由 `Router` 自动派发到同名 HTTP 方法（GET/POST/PUT/DELETE/PATCH）。
- 请求参数通过 `GetParameters()` 声明为 `map[METHOD][]string`，使用 `?` 前缀标记可选、`:` 分隔类型（string/int/float/bool/json/json-raw/json-array），由 `parseParameters` 统一校验并填充到 `RestResource` 字段。
- 错误与成功响应统一通过 `Response` 结构体及 `MakeResponse` / `MakeErrorResponse` 构造，HTTP 状态码始终为 200，业务状态由 `code`/`errCode`/`errMsg` 表达。
- 中间件以闭包函数形式返回 `gin.HandlerFunc`，并通过 `Options` 结构体的布尔/切片字段进行功能开关，新增字段保持零值默认行为以确保向后兼容。
- 跨请求共享的全局回调（如 BeforeCommitCallback）通过带 `sync.RWMutex` 保护的包级变量暴露 getter/setter 访问。
- 每个资源在启动时通过反射预计算方法表与参数映射缓存到 `metaCache`，运行时按 HTTP 方法直接反射调用，避免每次请求重复查找。
